\chapter{Introdução}
\label{cha:introduction}

Este documento apresenta a implementação do sistema CN2425TF, desenvolvido no âmbito da unidade curricular
de \textit{Computação Na Nuvem}. O sistema tem como objetivo fornecer funcionalidades que permitam aos utilizadores
a submissão de imagens para deteção e análise de monumentos, bem como a consulta de informações
sobre os mesmos, tal como nome e localização. A aplicação deve recorrer aos serviços disponibilizados pelo
Google Cloud Platform, nomeadamente os serviços \textit{Cloud Storage}, \textit{Firestore}, 
\textit{Pub/Sub} \textit{Cloud Functions}, \textit{Vision API} e \textit{Static Maps API}.

Este documento descreve os principais componentes da solução, incluindo os pressupostos assumidos
entre os diferentes componentes, o protocolo de comunicação entre eles, e o modelo de dados utilizado
para a persistência de informação.
